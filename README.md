## Tujuan repository
Melatih siswa PPLG untuk membuat _repository_ di Github dengan Website buatan mereka sendiri secara. Sehingga kedepannya mereka terbiasa menggunakan GitHub sebagai platform untuk menyimpan, mengelola, mendokumentasikan, dan memamerkan proyek-proyek yang telah dibuat. Selain itu, kegiatan ini diharapkan dapat menjadi langkah awal dalam membangun portofolio digital serta mengenal workflow pengembangan perangkat lunak.
